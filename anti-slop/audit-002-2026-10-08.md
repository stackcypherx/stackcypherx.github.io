### Found during verification and fixed (outside the 20, please review)

- **V-1, R-34: dark mode was lost on every in-site link click.** Astro's View Transitions replace
  the `<html>` attributes, and the theme script only ran on full loads. This bug predates this
  pass. Fix: re-apply the stored theme to the incoming page on `astro:before-swap`.
- **V-2, C-2: double init.** `init()` could run twice per page (readyState plus `astro:page-load`),
  which would bind the theme toggle twice and make it toggle back. Guarded with a per-body flag.
- **V-3, R-03: hidden machine-chip checkboxes took up 20px** because of a specificity clash.
  Fixed selector.
- **V-4, R-27: progress could be lost silently.** If the browser blocks storage, a warning now
  appears in the progress panel, and export, import and reset now show a status message.
