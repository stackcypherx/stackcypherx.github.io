# antislop audit 001 (2026-10-07)

Scope: the whole Astro site at commit 3c7f9d6 (18 pages, `src/`). Mode: AFTER.
Direction: `DESIGN.md` (transcribed from the existing editorial design).
Design Read: personal portfolio and public learning plan for security and network hiring managers,
in an editorial printed-report language, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

Method: read the stylesheet, layouts, components, pages and client script; ran every palette
pairing through the antislop contrast checker; built the site locally (18 pages, builds clean).
No browser click-through yet. That happens in the fix pass (R-35).

The base is in good shape. No gradients, glows, fake testimonials, invented stats, dead nav
links, bento grids or fake terminals. The numbers shown (years, provinces, builds, credentials)
come from your data files. Most findings are contrast, tap size, em dashes and leftover motion.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

## HIGH

1. **R-02, em dashes everywhere.** About 330 in source (2,360 in built HTML, including the
   search index). They are in every page, every data file, the `<title>` separator
   (`Experience — Dickie`) and the footer disclaimer. Fix: replace with period, comma, colon or
   parentheses, sentence by sentence; title separator becomes `·` or `|`.

2. **R-25, secondary grey fails AA in light mode.** `--ink-3` `#828176` on paper is 3.79:1
   (3.51:1 on `--paper-2`). It carries small text: `.dim`, `.tag`, `.chip`, `.stat .l`, table
   headers, `.figure`, `.eyebrow`, rail links, palette hints, input placeholders. Dark mode
   passes (4.95:1). Fix: darken `--ink-3` to about `#6b6a60` and re-check.

3. **R-25, faintest grey used as text.** `--ink-4` on `.m .d` (machine difficulty on Labs):
   2.36:1 light, 2.85:1 dark. Fix: use `--ink-3` (after #2) for that text; keep `--ink-4` for
   markers and separators only.

4. **R-25 (non-text, WCAG 1.4.11), controls nearly invisible.** Checkbox border `--rule-2`
   is 1.76:1, the search underline 1.76:1, header button borders `--rule` 1.39:1 (dark: 1.92:1
   and 1.37:1). Progress checkboxes are the main interaction on Roadmap and Labs. Fix: control
   borders at 3:1 or better (`--ink-3` works once #2 is done).

5. **R-32, search palette keyboard handling.** `.cmdk-in { outline: 0 }` has no replacement
   focus style; Tab can leave the open dialog and land on the page behind it; closing does not
   return focus to the Search button. Fix: visible focus style, simple focus trap, restore focus
   on close.

6. **R-03, tap targets under 44px.** Menu, search and theme buttons are 32px; checkboxes 15px;
   filter chips on Labs about 20px tall; `.btn-sm`; the `open ↗` room links; rail links. Fix:
   44px hit area through padding (visual size can stay small), gaps between neighbours.

7. **R-38 / C-5, stale claim in the colophon.** Footer says "Astro · hand-written CSS ·
   canvas". The canvas was removed (CSS hides it; `ui.ts` header still describes a "hero network
   canvas"). Fix: drop "canvas" from the colophon and the script comment.

8. **R-17 / R-27, counters render as 0.** Stat numbers ship as `0` in HTML and count up with
   JS. Without JS, before the observer fires, or in link previews and crawlers, the page says
   "0 Years in telecom". Track cards show `—` until hydration. Fix: render the real number
   server-side; drop the count-up (see #9).

## MEDIUM

9. **R-19, motion without a stated purpose, against MOTION 1.** 44 blocks fade up on scroll
   with staggered delays, stats count up, the timeline observer adds a class nothing styles.
   An editorial report does not animate in. Fix: remove `data-reveal` and the counters; keep
   hover/colour transitions and the page cross-fade.

10. **R-06, wide-tracked uppercase labels on nearly every block.** About 15 classes use it
    (`.tag`, `.chip`, `.eyebrow`, `th`, `.stat .l`, `.exit b`, `.check-e b`, `.rec-do b`,
    `.fchip`, `.rrow a`, `.brand-sub`, palette `.s`). The CSS comment says "used sparingly";
    52 uses in markup say otherwise. Fix: keep it for one role (section labels above the
    numbered heads), set the rest in small sentence-case sans.

11. **R-08, arrows as decoration.** `↗` on external links is a consistent signal: keep it and
    write the reason. `→` on internal links ("Open →", "Recommendation 8 →", "Software built →",
    "All six builds →") and in front of every timeline output is decoration. Fix: drop `→`
    except where it signals "continue to the next page" once per page.

12. **R-01 / R-31, left stripes without meaning.** `.note-box.warn` and `.ok` mark a state:
    keep. Plain `.note-box`, `.panel`, `.rec-do` and `pre` carry a stripe for looks, and the
    plain note-box uses the rust accent that DESIGN.md reserves for numbers and current state.
    Fix: remove the decorative stripes, or use a hairline rule above instead.

## LOW

13. **R-36 (copy), the "Not X. Y." formula is a tic.** Around 25 instances: "Not a career
    change. A specialisation.", "That is not a reset", "Not a beginner's plan.", "Not at
    zero.", "not a screenshot", "not a skill"... Once is voice; 25 is a pattern. Fix: keep the
    best two or three (the home heading earns it), rewrite the rest as plain statements.

14. **C-5 (copy), unsourced comparative claims.** "the overlap almost nobody occupies",
    "context most security candidates never get". They read as confident, but a hiring reader
    can't check them. Fix: state what you do and let the reader make the comparison.

15. **R-05, the same four-stat row twice.** Home and Experience both open with four equal stat
    cards right below the hero. The numbers are real, so this is not R-17, but it is the
    hero-plus-stats template. Fix: keep it on Experience; on Home, fold the facts into the lede
    or the Position section.

16. **C-1, leftover code from the previous design.** `canvas { display: none }`,
    `.hero-canvas`, `.brand-dot`, `.spot::before`, `.marquee`, `.tl::before`,
    `.xp-item::before`, `initSpotlight` (writes `--mx/--my` that nothing reads), the timeline
    observer. Fix: delete.

17. **C-5, hardcoded counts.** "Six systems", "All six builds", "The 13 recommendations",
    "84-room" are correct today, but will go stale when the data changes. Fix: derive from
    `builds.length`, `recommendations.length`, `totalRooms`.

18. **R-03, overflow masked, bare hamburger.** `body { overflow-x: hidden }` hides any
    horizontal overflow instead of surfacing it; the mobile menu button is a bare `☰`. Fix:
    remove the mask and fix what shows up; label the button "Menu".

19. **R-21 / R-34, dark-mode browser chrome.** `<meta name="theme-color">` is fixed to the
    light paper colour, so dark mode keeps a light address bar on mobile. Fix: update it in the
    theme toggle.

20. **C-2, social card promises an image.** `twitter:card` is `summary_large_image` but there is
    no `og:image`. Fix: switch to `summary`, or add a real image (asset to be confirmed, R-23).
